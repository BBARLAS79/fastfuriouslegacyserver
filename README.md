# Fast Furious Legacy Private EA Server


This server is for the Fast & Furious Legacy  game in Early Access.

For Fast & Furious 6: The Game, visit here: https://github.com/Win-DVD/ff6-server (Thanks WinDVD)

The project has many bugs, and the server is not fully playable. It is for preview purposes only. All bugs will be fixed with updates.

The server runs on Node.js 11.

Tested versions:

V0.3.0 (Terrible support)

V2.1.0 (Excellent support)
